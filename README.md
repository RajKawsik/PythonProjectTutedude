# Python Learning Scripts

This repository contains a collection of Python scripts created for learning and practicing fundamental programming concepts. The scripts are organized into modules, each focusing on different topics.

## Project Structure

The project is structured into several modules (directories), each containing Python scripts related to a specific theme:

```
.
├── module 2/
├── Module 3/
├── module 4/
├── main.py
└── README.md
```

## Modules

### Module 2: Introduction to Python

This module covers the basics of Python programming, including input/output, variables, and simple calculations.

-   `assignment 1 module 2.py`: Performs basic mathematical operations (addition, subtraction, multiplication, division) and provides a personalized greeting.
-   `challenge.py`: Includes scripts for temperature conversion (Celsius to Fahrenheit and vice-versa) and a simple interest calculator.
-   `simple program.py`: A basic "hello world" style program that demonstrates user input.

### Module 3: Control Flow

This module focuses on control flow statements, allowing for more complex program logic.

-   `assignment 2 module 3.py`: A script to check if a number is even or odd and another to calculate the sum of integers from 1 to 50 using a `while` loop.
-   `elif.py`: A simple command-line calculator that uses `if-elif-else` statements to perform operations.
-   `for.py`: Demonstrates the use of `for` loops with different data types like lists and strings, and with the `range()` function.
-   `range.py`: Explains how the `range()` function works with start, end, and step parameters.
-   `while.py`: Contains examples of `while` loops.

### Module 4: Functions and Modules

This module introduces functions and the concept of modularity in Python.

-   `assigment 3 module 4.py`: A script to calculate the factorial of a number using recursion and another that uses the `math` module for operations like square root, logarithm, and sine.
-   `function.py`: Covers the basics of defining and calling functions.
-   `Local and global variables.py`: Explains the concepts of local and global variable scopes.
-   `Modules.py`: Demonstrates how to import and use Python modules.
-   `pass arguments to the function.py`: Shows how to pass arguments to functions.
-   `passing functions as arguments.py`: Explains how to pass functions as arguments to other functions.
-   `recursion(calling function within function).py` & `recursive function(2).py`: Provides examples of recursive functions.
-   `return statements.py`: Explains the use of the `return` statement in functions.

## How to Use

To run any of the scripts, navigate to the script's directory and execute it using the Python interpreter:

```bash
python3 "module 2/simple program.py"
```
